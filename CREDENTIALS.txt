APPROVAL WORKFLOW SYSTEM (2-LEVEL HIERARCHICAL)
=====================================================

OVERVIEW:
The system uses a 2-level approval hierarchy that applies across multiple modules:
- Level 1: Pending (0/2)
- Level 2: Supervisor Approved (1/2)
- Level 3: Manager Final Approval (2/2 - LOCKED)

✅ CURRENTLY ACTIVE IN:

1. BILL OF MATERIALS (BOM) - Master Data Module
   ✓ IMPLEMENTED & TESTED
   Supervisor: Approve component specifications (0/2 → 1/2)
   Manager: Final approval of BOM (1/2 → 2/2)
   When Fully Approved: BOM becomes READ-ONLY, no edits allowed

⏳ PLANNED FOR (Framework Ready - useApprovalWorkflow):

2. INVENTORY MANAGEMENT MODULE

   B) Stock Outbound
      Supervisor: Verify item availability, condition check

      When Locked: Stok updated, barang keluar tercatat
   
   C) Internal Transfer
      Supervisor: Verify quantity at source warehouse
      Manager: Approve transfer to destination

      Supervisor: Verify budget ketersediaan, qty kebutuhan

      When Locked: PR finalized, ready for PO creation
   
   B) Purchase Order (PO)
      Supervisor: Verify supplier, price, terms
      Manager: Approve untuk dikirim ke supplier
      When Locked: PO terkirim, tidak bisa diubah
   
   C) Return Slip (RS)
      Supervisor: Verify returned items, confirm condition
      Manager: Approve return processing & credit memo
      When Locked: Return selesai, stok diperbaharui

4. PRODUCTION MODULE

      Supervisor: Verify material availability, routing
      Manager: Approve WO release to production floor
      When Locked: Production dapat dimulai

   A) Batch Release
      Supervisor: Verify QC test results complete
      Manager: Final approval untuk release batch to sales
      When Locked: Batch released, ready for shipment

6. SALES MODULE
   
   A) Sales Orders (SO)
      Supervisor: Verify pricing, customer credit limit
      Manager: Approve SO untuk processing
      When Locked: SO confirmed, ready for delivery

APPROVAL HIERARCHY RULES:

✓ Supervisor (Level 2) CAN:
  - Approve Level 1 (0/2 → 1/2)
  - Reject/Reset approval back to pending (0/2)
  - Edit/Modify documents while at 0/2 or 1/2
  - View fully approved documents (READ-ONLY)

✓ Manager (Level 3) CAN:
  - Approve Level 2 ONLY (1/2 → 2/2)
  - CANNOT approve if Supervisor hasn't approved first
  - Reject/Reset approval back to pending (0/2)
  - View fully approved documents (READ-ONLY)
  - Cannot edit locked documents

✓ Director (Level 4) CAN:
  - ⚡ DIRECT FULL APPROVAL (0/2 → 2/2 in 1-step)
  - Skip supervisor approval requirement
  - Approve from any status (0 or 1) directly to fully approved (2/2)
  - Reject/Reset approval back to pending
  - All Manager permissions

✓ Master Admin (Level 10) CAN:
  - ⚡ DIRECT FULL APPROVAL (0/2 → 2/2 in 1-step)
  - Skip all approval requirements
  - Complete unrestricted access
  - Override any approval status
  - Emergency system access

⚠️ BLOCKING RULES:
  - Manager (Level 3) cannot approve status 0/2 (must wait for Supervisor first)
  - User gets warning: "Approval 1/2 (Supervisor) must be completed first"
  - Director & Master Admin bypass all blocking rules
  - When fully approved (2/2): Document locked, all fields READ-ONLY
  - To make changes on locked doc: Manager+ must REJECT first
