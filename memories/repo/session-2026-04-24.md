# ERP Manufacturing — Session Memory 2026-04-24

## 🏗️ Project Overview
**ERP Manufacturing** is a web-based ERP system designed for small business manufacturing.
- **Tech Stack:** Node.js 20, Express, TypeScript (Backend) | Vue 3, Vite, TS, Tailwind CSS (Frontend) | MariaDB 10.4 (XAMPP).
- **Workspaces:** Monorepo using npm workspaces (`backend/` and `frontend/`).
- **Start Command:** `npm run dev` at the root directory runs both backend and frontend concurrently.

## 🔑 Key Architecture Notes
- **JWT Payload:** Uses `{ userId, userLevel }`. Backend access is via `req.user.userId` (NOT `req.user.id`).
- **Database Migrations:** Schema is checked and patched on backend startup (`backend/src/config/database.ts`).
- **Approval Gate:** Fund requests and other approvals usually require `userLevel >= 4` (Admin/Director).
- **Recent Modules (April 2026):**
  - **Fund Request:** Multi-line items, per-item approval, state-machine for statuses, auto-pay AP integration.
  - **Approval Inbox:** Centralized global inbox for approving items (with enriched responses for `fund_request`).
  - **Aesthetics:** Pill buttons with tinted backgrounds, SVG icons, and micro-interactions applied recently.
